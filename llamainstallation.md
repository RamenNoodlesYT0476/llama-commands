# Installing `llama-cli` on macOS Terminal

The fastest way to install `llama-cli` on macOS is using **Homebrew**. It automatically compiles `llama.cpp` with native Metal GPU acceleration for Apple Silicon.

---

## Prerequisites
* **macOS 12.0 (Monterey)** or newer.
* **Terminal app** (or iTerm2 / Warp).

---

## Installation Steps

### Step 1: Install Homebrew (if not already installed)
Open Terminal (`Cmd + Space` -> type **Terminal** -> press `Enter`) and run:

```bash
/bin/bash -c "$(curl -fsSL [https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh](https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh))"
